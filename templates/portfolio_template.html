CLI Commands Helper

To add a stock to your portfolio:

python main.py --portfolio-add AAPL

To remove a stock:

python main.py --portfolio-remove AAPL

To list all portfolio stocks:

python main.py --portfolio-list

To trigger research runs for the whole portfolio:

python main.py --portfolio-run

To schedule daily runs (cron daemon):

python main.py --cron "0 17 * * *"
