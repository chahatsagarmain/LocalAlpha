# LangGraph Agents & Reflection Logic

This document details the multi-agent design, prompt engineering strategies, quantitative auditing constraints, and LangGraph routing edges implemented in LocalAlpha.

---

## 1. LangGraph State Management

LangGraph execution revolves around the `AgentState` schema, represented by a Python `TypedDict`. As the state passes through the nodes, each node returns values that update the shared state dictionary.

```python
from typing import TypedDict, List, Dict, Any

class AgentState(TypedDict):
    ticker: str                 # Stock symbol being audited
    run_date: str               # ISO date YYYY-MM-DD
    indicators_summary: str     # Raw text output of computed pandas_ta indicators
    news_summary: str           # Scraped DuckDuckGo news summaries and URLs
    historical_context: str     # Previous prediction and closing price context
    rolling_accuracy: float     # Database rolling prediction accuracy score (0.0 to 1.0)
    
    # Core Agent Outputs
    researcher_draft: str       # Current markdown draft generated by the Researcher
    predicted_trend: str        # 'Bullish', 'Bearish', or 'Neutral'
    reviewer_critique: str      # Critique feedback provided by the Reviewer
    approved: bool              # Validation status of the audit
    revision_count: int         # Count of correction loops executed (max 2)
    revision_log: List[dict]    # List of history tracking drafts, critiques, and approvals
```

## 3. Reviewer Agent (Auditor)

* **System Prompt:** Located in [agents/prompts.py](file:///D:/distributed-crawler/LocalAlpha/agents/prompts.py#L30).
* **Role:** Acts as a Senior Risk Officer and Auditor.
* **Responsibilities:**
  - Evaluates the Researcher's draft analysis for mathematical and logical alignment with computed market indicators.
  - Generates critique instructions on contradictions, prompting adjustments.
* **Audit Rules Checked:**
  - **Overbought Bullish Audit:** If the Researcher claims a "Bullish" trend, the Reviewer flags a contradiction if the RSI is in the overbought zone ($> 75$) or if the closing price exceeds the Upper Bollinger Band, suggesting overextension.
  - **Oversold Bearish Audit:** If the Researcher claims a "Bearish" trend, the Reviewer flags a contradiction if the RSI is in the oversold zone ($< 25$) or if the closing price is below the Lower Bollinger Band, suggesting support/rebound.
  - **MACD Trend Alignment:** Flags claims of "upward momentum" that conflict with a declining MACD histogram or a bearish signal line crossover.

## 4. Conditional Edge Router (`should_continue`)

The execution graph routes states dynamically based on validation criteria:

```python
def should_continue(state: AgentState):
    # Route to END if Reviewer approves or we reach the 2-cycle safety limit
    if state.get("approved") is True or state.get("revision_count", 0) >= 2:
        return "end"
    # Otherwise, loop back to the Researcher for corrections
    return "continue"
```

The maximum revision limit of 2 is an essential guardrail. It prevents infinite looping during edge cases where the LLM struggles to resolve a critique (such as a local model repeating contradictory phrasing), forcing a graceful exit and saving the final draft.

## 5. Offline Simulation Engine (Mock Mode)

To facilitate offline testing and CI/CD validation, the orchestrator includes a simulated agent engine triggered by `config.MOCK = True` (or `--mock` CLI argument).

1. **Researcher Simulation:**
   - Detects the RSI value from the text summary.
   - On `revision_count == 0` (first draft) and RSI $> 70$: Intentionally generates a "Bullish" trend to trigger a Reviewer critique.
   - On `revision_count > 0` (revision loop): Corrects its prediction to "Neutral" to reflect the overbought indicators.
2. **Reviewer Simulation:**
   - Detects the trend and RSI value.
   - If `trend == "Bullish"` and RSI $> 70$ on the first cycle: Sets `approved = False` and outputs a critique detailing the overbought contradiction.
   - Otherwise: Sets `approved = True` and approves the draft.

This deterministic mock framework simulates the exact multi-agent reflection loop, logging state updates, updating the SQLite run logs, and rendering revision history timelines in the HTML template.
